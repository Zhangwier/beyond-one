# 超出一人之力 — BEYOND ONE

**一部完全由代码写成的动态图形短片**
*Written in code. Printed on paper.*

片长 84 秒 · 60 fps · 1920×1080 · 16:9 · H.264 High · AAC 320k
（工程同时支持 `--scale 2` 的 3840×2160 真 4K 渲染，不是放大）

---

## 一句话

> 一个人手里只有一条线。
> 这条线在八十四秒里，遇到了一双又一双手。
> 它没有变长。是拿笔的手，变多了。

**全片没有素材库，没有贴图，没有采样音乐，没有一段旁白。**
每一个像素、每一个音、每一个转场，都是从时间 `t` 算出来的。

---

## 为什么不是"AI 宣传片"

这部片子只回答一个问题：

> **当智能不再只能来自你自己的大脑，人类能够抵达的边界会发生什么变化？**

它的答案不是"更快"，而是**边界本身的形状变了**。所以它必须分三层说清楚：

1. 一个人的知识与时间有限，而问题经常横跨多个领域；
2. 协作让陌生的领域变成可触碰的；
3. 但机器会错，而错得很像对——最后一句必须由人来说。

片子里没有机器人、没有发光大脑、没有神经网络连线、没有代码雨。
出现的是：**纸、墨、一支笔、一张图纸、一份表格，和一条一直在动的线。**

---

## 视觉母题：THE REACH（一条线）

全片只有一个图形，一条**连续的墨线**。它的参数是：

| 参数 | 含义 | 在片中如何变化 |
|---|---|---|
| `from / to` | 人在这里，答案在那里 | 每一格都不同 |
| `bow` | 路径的弯度 | 弯曲代表思考，直线代表没有思考 |
| `err` | 高频抖动 | 这一格的难度 |
| `loop` | 末端回卷的小环 | 线"回头看自己"＝人核验机器 |
| `grew` | 已经画出的比例 | 永远按笔画顺序生长 |
| `th / dry` | 笔压与枯笔 | 人画的重、机器补的细而枯 |

它不是装饰。**每一格的含义都由几何本身承担**：

| 章节 | 线的状态 | 观众读到的意思 |
|---|---|---|
| 序 | 一个点，长成一个**合不拢的螺旋** | 一个人的能力有边界 |
| 一 | 螺旋散成问号，外面套三层等高线 | 问题的形状比人大 |
| 一·抵达 | 线冲出去，**急停**，差 210 px | 不是没答案，是答案在别人的领域 |
| 二 | 四条短枝，每条都**差一半**；外来的细线把它接满 | AI 把缺的那一半递到手边 |
| 三 | 一个想法分裂成 32 个带证据的分支 | 想法自己长出了手 |
| 三·纵深 | 同一根线被拉过四层尺度（1→26→60→1846） | 一行代码背后是一座城 |
| 四·讹 | 纸翻成负片，线**不动** | 它答得很像，但错了 |
| 四·核 | 线**第一次回头**，闭合成环 | 人核验、修正、重新决定 |
| 终 | 线以 8 重对称复制成轮，再**解开成螺旋** | 线没变长，手变多了 |
| 终·句 | 只剩一个句号，和第一帧一样大 | 回到起点，但意思不同 |

> 关键约束：**全片任何一帧都只有一条主线**。"复制"只在终章发生，而且复制本身
> 就是那一章唯一的论点。

## 视觉规范

| 项 | 规定 |
|---|---|
| 纸 | 骨白 `#E9E2D3`，带帘纹、纤维、极稀疏杂质、光学暗角 |
| 墨 | `#15120E`，以**正片叠底**压在纸上，所以字母里能看见纸纹 |
| 灰 | `#6B655B`（已废弃的结论、次要标注） |
| 朱红 | `#B7351F`，**全片只用两次**：代码的三处缝、被划掉的三句错话 |
| 负片 | 只在第四章用一次（54–62 s），纸变墨、墨变纸 |
| 字体 | 思源宋体（人、正文、标题）／思源黑体（机器、坐标、编号），仅此两族 |
| 网格 | 左侧 96–414 px 为文字栏，452–1824 px 为图栏，页脚为测量行 |
| 特效 | 无泛光、无镜头光斑、无 3D 空间、无粒子。只有纸、墨、笔压、枯笔 |

**为什么是纸？** 因为这部片子讲的是"知识"，而知识在我们手里一直是印在纸上的。
纸会脏、会透、会有毛边——这正好是"人参与过"的证据。

## 声音

音乐不是背景，是**时间轴本身**。84 秒 = 84 拍，60 BPM，**一拍一秒，一小节四秒**。

- 全片用纯 JS 加法合成（正弦簇、FM、滤波器噪声、共振峰），直接写 24-bit WAV；
- 段落与画面的每一刀都落在**同一份事件表**上（`audio/features.json`）；
- 渲染器不分析音频波形，而是直接读合成器知道的**精确事件时间**——所以 60 fps 下不会漂。

| 段落 | 时间 | 音乐 | 画面 |
|---|---|---|---|
| 序 | 0–12 | 单音 A、两拍一次心跳、十一响倒计时 | 点 → 螺旋 |
| 一 | 12–22 | 和声出现、琶音进入 | 问号 → 等高线 → 急停 |
| 二 | 22–34 | 低频进来，四小节 | 网格 → 四条补齐 |
| 二·语言 | 34–40 | 琶音加密 | 论文 → 结构 → 摘要 |
| 三 | 40–54 | 全奏，最密的一段 | 分支 → 代码 → 四层纵深 |
| 四 | 54–64 | **骤停**、不协和、然后一个干净的音 | 负片、划掉、闭合回路 |
| 终 | 64–84 | 重新进入 → 高潮 → 只剩一个 A | 轮 → 螺旋 → 一句话 |

响度：**−17.4 LUFS integrated**，真峰值 0.0 dBTP，LRA 11.4 LU。

## 结构（13 格，84 秒）

| # | 时间 | 格 | 事件 |
|---|---|---|---|
| T00 | 0–12 | 序 · 有限 | 第一帧一个墨点；螺旋每秒长一圈，**合不拢**；缺口被标注、被测量 |
| T01 | 12–20 | 一 · 复杂 | 问号 → 三层等高线 → 四种能力：证明／测量／程序／另一种语言 |
| T02 | 20–22 | 一 · 抵达 | 线冲出去，急停，缺口 210 px，三条"缺什么"的清单 |
| T03 | 22–34 | 二 · 连接 | 网格铺满；四条短枝；四条外来的细线逐一补齐；01/04 → 04/04 |
| T04 | 34–40 | 二 · 语言 | 论文正文 → 边注、编号、引用；三行中文摘要，每条都**钉回原句** |
| T05 | 40–46 | 三 · 展开 | 一个想法分裂 5 代 → 32 个带证据的叶 |
| T06 | 46–50 | 三 · 缝合 | 十行真实的 Python；三处缝在朱红下划线；①②③ |
| T07 | 50–54 | 三 · 纵深 | 同一根线被拉过四层尺度，落点 1,846 个文件 |
| T08 | 54–59 | 四 · 讹 | 硬切负片；三句自信的错话；逐句划掉；"这段是错的。" |
| T09 | 59–64 | 四 · 核 | 线回头，闭合成环；三处修正写在错话旁边；纸回来 |
| T10 | 64–72 | 终 · 复调 | 1→2→4→8 重对称；八种能力；轮子每拍转一格 |
| T11 | 72–78 | 终 · 超出 | 轮子**解开**成一条 6.2 圈的螺旋，滑出画右 |
| T12 | 78–84 | 终 · 一句话 | 两行字，被测量，被数；最后只有一个句号 |

## 技术实现

| 层 | 实现 |
|---|---|
| 渲染 | 手写 **WebGL2**，三个渲染目标：纸、墨、排版；一个合成 pass 做正片叠底 |
| 笔触 | 折线 → 弧长重采样 → 沿法线挤成带 → 片元着色器算**笔芯 / 枯笔 / 湿边** |
| 排版 | Canvas2D 逐字排布层，上传为纹理参与合成；字与墨走同一套纸纹 |
| 音频 | 纯 JS 合成器（`tools/score.mjs`），输出 WAV + 特征表 |
| 导出 | Playwright 驱动无头 Edge（ANGLE/D3D11）→ PNG 帧 → ffmpeg |
| 确定性 | `render(t)` 是纯函数；不用 `Date.now` / `Math.random` / 累加状态 |
| 并行 | N 个无头页面轮流取帧，一个 ffmpeg 按序编码（默认 4 路） |
| 4K | `--scale 2` 时所有渲染目标、笔触、字号按物理像素重建 |

单帧 GPU 成本（AMD Radeon 780M，ANGLE-D3D11）：**平均 10.8 ms**
最重的一格（四层纵深）27.7 ms，最轻的一格 6.7 ms。

## 如何运行

```bash
npm install                       # 只依赖 playwright-core

npm run score                     # 重新合成配乐（84 s，约 20 s）
npm run serve                     # 预览 http://127.0.0.1:5177/

# 单帧（改镜头/调构图时最常用）
node tools/capture.mjs stills --t 6.4,21.2,49.4 --out out/stills/check

# 一格的联系表
node tools/capture.mjs sheet --from 12 --to 20 --n 9 --cols 3 --out out/sheet.png

# 一段（带声音）
node tools/capture.mjs clip --from 0 --to 12 --fps 60 --workers 4 --out out/clip.mp4

# 全片
node tools/capture.mjs film --fps 60 --crf 15 --workers 4 --out out/beyond_one_1080p60.mp4

# 4K
node tools/capture.mjs film --fps 60 --crf 18 --scale 2 --out out/beyond_one_4k.mp4
```

预览快捷键：`空格` 播放/暂停 · `←/→` ±1 s（`Shift` ±5 s）· `,/.` 单帧 · `[/]` 上一格/下一格 · `h` 隐藏 HUD
