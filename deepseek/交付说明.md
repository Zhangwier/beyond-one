# 交付说明 —《超出一人之力 / BEYOND ONE》

## 成片

| 文件 | 说明 |
|---|---|
| `out/beyond_one_1080p60.mp4` | **主成片**。1920×1080 / 60 fps / H.264 High / yuv420p / BT.709 / AAC 320k / 84.0 s |
| `out/beyond_one.zh.srt` | 中文字幕（24 条），与画面内排版逐条对齐 |

## 一句话

> 一个人手里只有一条线。八十四秒里，它遇到了一双又一双手。
> **它没有变长。是拿笔的手，变多了。**

---

## 这不是说明书

全片没有旁白、没有人物、没有对白、没有机器人、没有发光大脑、没有神经网络连线、没有代码雨、没有粒子。
只有**纸、墨、一支笔、一张图纸、一份表格，和一条一直在动的线**。

它要回答的是：

> **当智能不再只能来自你自己的大脑，人类能够抵达的边界会发生什么变化？**

答案分三层：边界有限 → 边界可被接续 → 但机器会错，最后一句必须由人来说。

---

## 视觉母题：一条线（THE REACH）

全片任何一帧**只有一条主线**。它的状态由六个数字决定：`from/to`（人在哪、答案在哪）、
`bow`（弯度）、`err`（抖动）、`loop`（末端回卷）、`grew`（已画比例）、`th/dry`（笔压与枯笔）。

每个章节改变这些数字的方式都有含义：

| 章节 | 线的状态 | 观众读到的 |
|---|---|---|
| 序 | 一个点长成**合不拢的螺旋**（0.86 圈） | 一个人的边界 |
| 一 | 螺旋散成问号，外套三层等高线 | 问题比人大 |
| 一·抵达 | 冲出去，**急停**，缺口 210 px | 答案在别人领域 |
| 二 | 四条短枝都差一半；外来细线逐一补齐 | AI 把缺的一半递过来 |
| 三 | 一个想法分成 32 个带证据的枝 | 想法长出了手 |
| 三·纵深 | 同一根线被拉过 1 → 26 → 60 → 1846 | 一行背后是一座城 |
| 四·讹 | 纸翻成负片，线**不动** | 答得像，不等于对 |
| 四·核 | 线**第一次回头**，闭合成环 | 人核验、修正、负责 |
| 终 | 8 重对称成轮，再**解开**成 6.2 圈螺旋 | 线没变长，手变多了 |
| 终·句 | 只剩一个句号 | 回到起点，意思不同 |

"复制"只发生在终章，因为复制本身就是那一章唯一的论点。

## 视觉规范

- **纸** `#E9E2D3`，带帘纹、纤维、极稀疏杂质、光学暗角；
- **墨** `#15120E`，以正片叠底压在纸上，所以字母里能看见纸纹；
- **朱红** `#B7351F`，**全片只用两次**：代码的三处缝、被划掉的三句错话；
- **负片** 只在第四章出现一次（54–62 s）；
- **字体** 思源宋体（人）/ 思源黑体（机器），仅此两族；
- **网格** 文字栏 96–414 px，图栏 452–1824 px，页脚为测量行；
- **特效** 无泛光、无光斑、无 3D 空间、无粒子；只有笔芯、枯笔、湿边、纸纹。

---

## 声音

84 秒 = 84 拍，**60 BPM，一拍一秒，一小节四秒**。全片配乐是纯 JS 合成的（加法合成 / FM / 滤波噪声），
直接写 24-bit WAV，同时导出精确事件表。

渲染器**不分析波形**，而是直接读合成器知道的事件时间——所以 60 fps 下画面与鼓点不会漂。
剪切的每一刀都落在拍点或重拍上。

第四章有一个刻意的**骤停**（54 s 硬切负片），之后是不协和长音，直到 59 s 才解决。

## 技术栈

| 层 | 实现 |
|---|---|
| 画面 | 手写 WebGL2 + 三个渲染目标（纸 / 墨 / 排版）+ 正片叠底合成 |
| 笔触 | 折线 → 弧长重采样 → 沿法线挤成带 → 片元着色器算笔芯 / 枯笔 / 湿边 |
| 排版 | Canvas2D 逐字排布 → 纹理 → 参与同一套纸纹合成 |
| 音乐 | 纯 JS 合成器（`tools/score.mjs`） |
| 导出 | Playwright 驱动无头 Edge（ANGLE/D3D11）→ PNG 帧 → ffmpeg |
| 确定性 | `render(t)` 是纯函数；不用 `Date.now` / `Math.random` / 累加状态 |
| 并行 | 4 个无头页面轮流取帧，单个 ffmpeg 按序编码 |
| 4K | `--scale 2` 时全部渲染目标 / 笔触 / 字号按物理像素重建 |

实测单帧 GPU 成本（AMD Radeon 780M）：平均 **10.8 ms**，最重 27.7 ms，最轻 6.7 ms。
全片 5040 帧，4 路并行约 **8 分钟** 完成。

## 如何重建

```bash
npm install                       # 只依赖 playwright-core

node tools/score.mjs              # 重新合成配乐（84 s）
node tools/serve.mjs 5177         # 预览 http://127.0.0.1:5177/  (?t=12  ?scene=verify)

node tools/capture.mjs stills --t 6.4,21.2,49.4 --out out/stills/check
node tools/capture.mjs sheet --from 12 --to 20 --n 9 --cols 3 --out out/sheet.png
node tools/capture.mjs clip  --from 0 --to 12 --fps 60 --workers 4 --out out/clip.mp4
node tools/capture.mjs film  --fps 60 --crf 15 --workers 4 --out out/beyond_one_1080p60.mp4
node tools/capture.mjs film  --fps 60 --crf 18 --scale 2 --out out/beyond_one_4k.mp4
node tools/perf.mjs               # 逐格测帧成本
node tools/subtitles.mjs          # 重新生成 .srt
```

预览快捷键：`空格` 播放/暂停 · `←/→` ±1 s（`Shift` ±5 s）· `,/.` 单帧 · `[/]` 切格 · `h` 隐藏 HUD。
