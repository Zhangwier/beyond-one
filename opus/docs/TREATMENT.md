# 《超出一人之力》 Treatment & Style Bible

> 当智能不再只能来自我们自己的大脑，人类能够抵达的边界会发生什么变化？

## 0. 从 pdoom-video 学到的（方法，而非外观）

| 参考项目的做法 | 在本片中的迁移 |
|---|---|
| 每一帧是歌曲时间 t 的纯函数，预览与导出一致 | `renderFrame(ctx, scenes, t)`：浏览器与 Node(Skia) 跑同一份 Canvas2D 代码；无 `Math.random`/`Date.now`，随机数全部播种 |
| 时间数据来自分析好的 `audio.json`，剪辑点吸附到节拍网格 | 更进一步：**乐谱本身就是时间轴**。`score.ts` 定义 BPM、小节与命名 cue，合成器从它写音乐，场景从它读时间，二者不可能漂移 |
| 一条贯穿全片的母题（火花与它拖出的线） | 原创母题：**一**（单个横画）——“一”个人，也是一个人能伸展的距离 |
| “字就是画面”：歌词被写、被盖章、被编织 | 中文字本身是结构：一 → 尺寸线 → 路径 → 横轴 → 大 → 地平线 |
| 统一调色板、字体层级、克制特效 | 两种底色 + 两种语义色，三种字体声部，只有颗粒与暗角两种后期 |
| 一场景一模块，可单独预览 | `src/scenes/*.ts` 各自独立，`stills/sheet` 可单独渲染任意时间 |
| 动态模糊：多子帧平均 | 场景通过 `samples(t)` 声明快速运动段需要的子帧数，渲染器做精确的累积平均 |

我们**没有**沿用：橙色火花、P(doom) 数值、任何具体的转场或场景、three.js 着色器管线。

## 1. 三个候选方案

**A. 「圆」** 个人能力是一个半径固定的圆，AI 让圆变成可展开的折纸。——直观，但“能力圈”是常见隐喻，且折纸三维化工程风险高、隐喻偏装饰。

**B. 「拼图」** 一个问题是一张缺块的拼图，AI 补齐缺块。——叙事清楚，但暗示 AI“补齐”人的空缺，弱化了人的判断，第三层思想难以成立。

**C. 「一」（选定）** 一个人 = 一个横画。它是汉字里最简单的字，也是一条有长度的线：
- 它可以被测量（能力边界），可以被延长（AI 搭桥），可以成为图表横轴（数据），
- 最后，红色的“人”（判断）写在它上面，成为“大”；镜头拉远，“大”的横画找不到尽头，变成地平线。
- 序章与终章是同一个镜头语法的镜像：序章从巨大的笔画拉远，发现它只是旷野中的短线；终章拉远，却永远找不到它的端点。

选择 C 的理由：母题本身就是中文字，可以“字成结构”；每一次变形都有因果（测量→不足→连接→延伸→被人校正→成字）；工程上全部是 2D 矢量，可在 CPU 上确定性渲染 4K。

## 2. 语义色彩（全片只允许这些）

| 名称 | 值 | 唯一含义 |
|---|---|---|
| 纸 paper | `#ECE8DF` | 白昼、清醒、核验（序章、第一章、第四章、终章） |
| 墨 ink | `#0D0E10` | 思考空间（第二、三章） |
| 石墨 / 灰 | `#5F5C57` / `#A39E95` | 次级信息、网格、标注 |
| **朱 human** | `#D2321F` | **只属于人的判断**：红笔、圈注、印章、“人” |
| **群青 machine** | `#2443C4` / 暗底 `#7C95FF` | **只属于 AI 的贡献**：连接线、白话翻译、草稿、延伸 |

观众无需旁白即可读出：蓝色出现在哪里，AI 就参与了哪里；红色出现在哪里，人就做了决定。终章的“大”同时含三色：墨色的核心（你本来会的）、群青的两臂（借来的延伸）、朱红的人（方向与判断）。

## 3. 字体声部

- **思源宋体 Noto Serif SC**：人的声音——问题、格言、终句、标题。
- **思源黑体 Noto Sans SC（Thin→Black）**：结构——领域名、步骤、数字。
- **IBM Plex Mono**：机器与数据——代码、单位、标注、计数。

## 4. 一个具体的问题

为了避免“AI 有哪些功能”的说明书，全片只跟随一个具体、个人、跨学科的问题：

> **家门口这条河，还能游泳吗？**

它真实地需要：标准（GB 3838—2002 Ⅲ类含游泳区，粪大肠菌群 ≤ 10000 个/L）、微生物、采样、编程、统计（和水化学——被 AI 判断为此题暂不需要）。
片中数据为确定性生成的 30 天示例数据（降雨后 1–2 天菌落升高），代码中的相关系数与超标天数都由这份数据实际算出（滞后 1 天 r = 0.80；正确限值下 6/30 天超标）。

**有意设计的错误**：AI 写的代码把“个/L”的限值直接用于“个/100mL”的计数（`LIMIT = 10000`），宽松了 10 倍。它在第三章第 18 小节就出现在屏幕上，但不被强调——就像真实的 AI 错误一样看起来合理。

## 5. 结构（100 BPM，1 小节 = 2.4 s，第 0 小节 = 0.5 s）

| 小节 | 时间 | 章节 | 画面 | 声音 |
|---|---|---|---|---|
| — | 0–0.5 | 开场 | 14 倍放大的“一”被一笔写出 | 笔刷扫过 |
| 0–4 | 0.5–10.1 | 序章 · 有限 | 尾端落下（重击）→ 镜头拉远：巨大的笔画只是旷野中的短线；尺寸线“一个人”；知识/时间/精力三项有限；“想做的事”布满旷野，能力带内的只有少数；镜头钻进远处一个圈 | 低音持续 + 每拍钟表滴答 |
| 4–10 | 10.1–24.5 | 一 · 复杂 | 问题被逐字打出；关键字各射出一条引线，展开为六个学科（每拍一个）；那条“一”（恰好一张卡片宽）在学科下滑动，覆盖一个就遗忘上一个，独自学会全部的时间累加到 ≈ 4 年，第六个来不及；格言：现实的问题，从不按学科出现。 | 打字声 / 每个学科一个上行音 / 低频脉冲 / 屏息 |
| 10–16 | 24.5–38.9 | 二 · 连接 | 切到墨色。蓝线逐条连接（每条一声 FM 钟音），落在哪张卡片，哪张卡片的术语就被翻译成白话；水化学被划掉“这个问题暂时不需要”；卡片按依赖关系落成一排，曲线拉直成一条线：你会的（白）+ 借助 AI 可以抵达的（蓝）；格言：陌生的领域，变得可以进入。 | 鼓与贝斯进入 |
| 16–24 | 38.9–58.1 | 三 · 突破 | 沿着这条线移动的长镜头，四个步骤：研究（扫描标准，锁定 Ⅲ类那一格，数值飞出成为摘要）/ 编程（代码被写出，运行后每一行数据变成一个点飞走）/ 分析（点落在以这条线为横轴的图表上，降雨从顶部垂下，AI 画出限值线：超标 0/30）/ 表达（AI 草稿：可以放心游泳。）。角落的“所需时间”从 ≈ 4 年降到 ≈ 3 周 | 全段律动，每个步骤切换在强拍 |
| 24–29 | 58.1–70.1 | 四 · 判断 | 磁带停转 → 静默 → 灯亮（纸色）。四声滴答：人在想。红笔：等一下。圈出雨后的三个峰值：雨后为什么这么高？追溯到代码与标准：单位不一样，10000 个/L = 1000 个/100mL。修正：限值线**下坠一个数量级**（重低音），6 天变红；标题被划掉重写：雨后 48 小时内，不宜下水。盖上红色印章“人”。格言：能力可以借，判断不能借。 | 静默、滴答、红笔划纸声、下坠重击、盖章 |
| 29–35 | 70.1–84.5 | 终章 · 可能性 | 线回到纸面中心，四个成果折叠进线成为刻度，蓝色向两侧生长；印章里的“人”升起，在第 31 小节被写在“一”上：**大**（全片第一个大三和弦）。镜头拉远，“大”的横画找不到端点，变成地平线；序章的旷野回来，点逐一落入可及之处。终句：那件你以为一个人做不成的事，／现在，可以开始了。 | 上升 → D 大调高潮 → 宽阔的和声 |
| 35– | 84.5–88 | 标题 | 超出一人之力（“人”为朱红）／当智能不再只来自我们自己的大脑 | 一个音，一声低鸣 |

## 6. 每个元素为什么存在

- 网格十字：给旷野一个可测量的尺度，让“短”有参照。
- 点阵：“想做的事”的可视化统计；终章重现它，形成首尾呼应。
- “所需时间”计数：把“时间有限”从形容词变成数字，第三章中它的下降就是 AI 价值的量化表达。
- 引线：让观众看见“学科是从问题里长出来的”，而不是凭空堆砌的图标。
- 蓝色曲线变直线：问题分解 = 从网状关系到可执行路径。
- 图表横轴就是那条线：数据分析不是另一个画面，而是延伸本身。
- 限值线下坠：判断的后果被物理化，“改一个数字”有重量。
- 印章“人”：中文语境中“落款盖章”就是负责；它在终章变成“大”的一部分。
